After Effects 表达式字典 Official Ref

📌 属性与时间 (Global & Property)
时间驱动
time
返回当前合成的时间（秒）。无需关键帧即可驱动旋转或移动。
rotation = time * 150
随机摆动
wiggle()
最常用的随机函数。让数值在一定范围内随机波动。
wiggle(freq, amp)
图层序号
index
返回当前图层的序号。常用于阶梯式排列或延迟动画。
position[0] = index * 100
540
原始数值
value
代表当前属性在没有表达式时的数值（即你手动K的值）。常用于在原有动画基础上叠加效果。
value + wiggle(5,20)
📈 插值函数 (Interpolation)
Linear (匀速)
范围映射
linear()
将一个范围的数值映射到另一个范围。例如：声音越大，不透明度越高。
linear(t, tMin, tMax, val1, val2)
Ease (缓动)
平滑过渡
ease()
与 linear 类似，但首尾有缓动效果，运动更自然。
ease(t, min, max, v1, v2)
📐 向量与数学 (Vector & Math)
交互: 移动鼠标
lookAt()
让一个层（通常是3D）总是面朝向另一个点。用于摄像机跟踪或眼球运动。
lookAt(fromPoint, atPoint)
d = 145px
计算距离
length()
计算两个点之间的距离（长度）。常用于根据距离触发动画。
length(point1, point2)
正弦波
Math.sin()
正弦函数。生成周期性的波动数值，用于钟摆、漂浮、呼吸灯。
Math.sin(time * speed)
MAX
限制范围
clamp()
将数值限制在 min 和 max 之间。防止数值过大或过小。
clamp(val, min, max)
🎲 随机与杂色 (Random)
42.85
纯随机
random()
返回 0-1 之间或指定范围内的随机数。
random(min, max)
高斯分布
gaussRandom()
正态分布随机。结果更有可能接近平均值，比 random() 更自然集中。
gaussRandom()
🔒 81
锁定随机
seedRandom()
写在 random() 之前。如果设为 true，随机数将固定不变，不会每帧闪烁。
seedRandom(seed, true)
🎨 颜色转换 (Color)
色相循环
hslToRgb()
将 HSL (色相/饱和度/亮度) 转换为 RGB。非常适合做彩虹流光效果。
hslToRgb([h, s, l, a])
🌌 空间转换 (Layer Space)
3D转2D
toComp()
将图层内部的 3D 坐标点转换为合成视图的 2D 坐标。用于做 2D UI 追踪 3D 物体。
layer.toComp([0,0,0])
Auto Width
自适应尺寸
sourceRectAtTime()
获取文本或形状图层的实时边界框（宽、高、上边距等）。UI 自动化神器。
x.sourceRectAtTime().width
